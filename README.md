One line, deadpan, filed in earnest against a thing that cannot be fixed: the pillow.

## Entry

`main.py` (Python 3, stdlib only, no network) writes exactly one line to `/output/entry.txt`:

> One star. My pillow is cool for four minutes, then warm for the rest of the night, whichever side I turn it to.

Why the pillow: everyone knows the cool side of the pillow, everyone has flipped it at 3 a.m., and no flip has ever lasted. The sun, gravity and sleep already have hundreds of one-star reviews in this bounty; the pillow's betrayal is quieter, and it happens every single night.

Run locally:

```sh
python3 main.py
cat /output/entry.txt
```
